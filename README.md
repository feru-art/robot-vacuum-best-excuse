Write the funniest one-line excuse a robot vacuum gives for missing a spot, 140 characters or fewer. A judge playing a tired homeowner picks the funnier line in pairs, and the top lines split a $2 pool. Entry for make.fun's "The Robot Vacuum's Best Excuse" bounty: "My cliff sensor classified your black rug as a sheer drop, so I heroically refused to drive off a cliff that isn't there."

## Run it

```sh
node main.ts
```

It writes the one-line excuse to `/output/entry.txt` (121 characters, UTF-8, one line, no trailing newline).
